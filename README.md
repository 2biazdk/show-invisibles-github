# Show Invisibles on GitHub

Show spaces and tabs directly in GitHub code views.

This is a small Chrome extension originally published under Tobias Christian Jensen's personal developer account and now maintained by Forlæns / Forward plugins.

## Build

```sh
npm run build
```

The Chrome Web Store upload package is the generated `dist` folder.

To create the ignored `dist.zip` upload artifact:

```sh
npm run package
```
